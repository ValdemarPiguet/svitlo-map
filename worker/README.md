# Worker «Світло·Україна» (Telegram + попередження про екстрені відключення + форма зворотного зв'язку)

Файл: `svitlo-worker.js` (замінює старий `feedback-telegram.js`: форма зворотного зв'язку працює і тут).

## Що він робить
1. Раз на 3 години перевіряє джерела: новини на alerts.org.ua, публічні Telegram-канали зі списку `TG_CHANNELS`, ознаку `emergency` на svitlo.live.
2. Якщо бачить слова на кшталт «аварійні/екстрені відключення» (або «скасовано»), надсилає вам у Telegram повідомлення з цитатою, посиланням, списком областей і кнопками: «Увімкнути», «Вся країна», «Ігнорувати».
3. Після вашого підтвердження зберігає попередження в KV; сайт читає його через `GET /alerts` і показує смугу, знак «!» і картку в панелі області.
4. Попередження вимикається саме через 12 годин (змінюється `ALERT_HOURS`), вам приходить повідомлення.
5. Приймає форму зворотного зв'язку (`POST /` або `/feedback`) і пересилає в Telegram.

## Налаштування
1. **Бот.** @BotFather → `/newbot` → токен. Відкрийте чат з ботом і натисніть Start. Chat id: напишіть боту, відкрийте в браузері `https://api.telegram.org/bot123456789:AAAbbb…/getUpdates` (замість `123456789:AAAbbb…` вставте свій токен повністю, з двокрапкою, без дужок `< >` і пробілів) і знайдіть `"chat":{"id":…`. Якщо відповідь `404 Not Found`, токен вставлено з помилкою: перевірте його адресою `…/bot<токен>/getMe`, а новий можна отримати в @BotFather командою `/revoke`.
2. **Worker.** Cloudflare → Workers & Pages → Create → Create Worker → вставте `svitlo-worker.js` → Deploy.
3. **KV.** Cloudflare → Storage & Databases → KV → Create namespace (назва довільна). У Worker: Settings → Bindings → Add → KV namespace, змінна `KV`.
4. **Змінні** (Settings → Variables and Secrets):
   - `BOT_TOKEN` (Secret): токен бота
   - `CHAT_ID`: ваш chat id (керувати ботом може лише він)
   - `WEBHOOK_SECRET` (Secret): будь-який довгий випадковий рядок (латиниця й цифри)
   - `ALLOWED_ORIGIN`: `https://valdemarpiguet.github.io`
   - `TG_CHANNELS`: публічні канали через кому, без @ (наприклад: `ukrenergo`). Необов'язково, але саме вони дають найшвидший сигнал
   - `FEEDBACK_BOT_TOKEN` (Secret, необов'язково): токен **окремого** бота для форми зворотного зв'язку (створіть другого бота в @BotFather і натисніть в ньому Start). Без цієї змінної форма йде тим самим ботом, що й попередження. Веб-хук для цього бота не потрібен
   - `FEEDBACK_CHAT_ID` (необов'язково): куди слати форму; за замовчуванням ваш `CHAT_ID` (ваш id підходить для будь-якого вашого бота)
   - `SVITLO_API` (необов'язково): `https://dtek-api.svitlo-proxy.workers.dev/`
5. **Розклад.** Cloudflare → Workers & Pages → ваш Worker → Settings → **Triggers** → Cron Triggers → Add → `7 */3 * * *` (раз на 3 години, о :07; час за UTC). Частіше: `7 * * * *` (щогодини).
   Якщо розділу немає: (а) це має бути саме **Worker**, а не проєкт Pages (адреса Worker закінчується на `.workers.dev`, Pages на `.pages.dev`; у Pages крон-тригерів немає); (б) на сторінці Settings пошукайте на сторінці слова `Cron` або `Trigger` (Ctrl+F): розділ може називатися «Trigger Events»; (в) запасний шлях через API: `curl -X PUT "https://api.cloudflare.com/client/v4/accounts/<ACCOUNT_ID>/workers/scripts/<ІМ'Я_WORKER>/schedules" -H "Authorization: Bearer <API_TOKEN>" -H "Content-Type: application/json" --data '[{"cron":"7 */3 * * *"}]'` (токен із правом Workers Scripts: Edit). Нове розклад може розійтись по мережі до 15 хвилин.
6. **Веб-хук Telegram** (один раз). Відкрийте в браузері, підставивши свої значення:
   `https://api.telegram.org/bot123456789:AAAbbb…/setWebhook?url=https://адреса-вашого-worker.workers.dev/tg&secret_token=ВАШ_WEBHOOK_SECRET` (підставте свої значення без дужок `< >`)
   Має відповісти `{"ok":true,...}`.
7. **Сайт.** У `index.html` вставте адресу Worker у рядки `const FBK_URL='';` та `var ALERTS_URL='';` (без слеша в кінці). Завантажте файл на GitHub.

## Керування з Telegram (лише власник)
- `/on all [6h]` — попередження для всієї країни (за замовчуванням 12 годин)
- `/on kyivska-oblast odeska-oblast [6h]` — для областей (список: `/regions`; м. Київ: `kyiv`)
- `/off [all | область…]` — вимкнути
- `/status` — чинні попередження, стан джерел, імена `cpu` із svitlo.live
- `/fbtest` — надіслати тестове повідомлення окремим ботом форми й показати точну помилку Telegram, якщо щось не так
- `/update` — запустити оновлення графіків прямо зараз (потрібні `GH_TOKEN` і `GH_REPO`)
- `/checkdata` — показати, коли востаннє оновлювались дані сайту
- `/help`

## Перевірка після налаштування
1. Напишіть боту `/status`: має прийти стан джерел. Якщо джерело позначено «недоступне», решта працює.
2. `/on kyivska-oblast 1h`, відкрийте сайт: протягом ~2 хвилин з'явиться смуга зверху і «!» на бейджі Київської області. `/off`: знак зникне.

## Обмеження
- Читання публічних каналів через `t.me/s/…` не є офіційним API Telegram: може змінитися або обмежуватись. Тоді Worker повідомить про недоступне джерело.
- Розпізнавання областей за назвами у тексті не ідеальне: ви завжди підтверджуєте кнопкою і можете вказати області вручну.
- Ознака svitlo.live використовується, лише якщо `cpu` області є в `SVITLO_MAP` (за замовчуванням тільки `kiivska-oblast`). Назви інших `cpu` видно в `/status`.
- Перевірка раз на 3 години означає затримку виявлення до 3 годин: екстрені відключення бувають короткими. Тому для термінових випадків є ручна команда `/on` (вона діє миттєво). Якщо в одному циклі бачить і «введено», і пізніше «скасовано», про введення не питає, а про скасування питає лише коли попередження було ввімкнене.
- Про недоступність джерела повідомляє після 2 перевірок поспіль (≈ 6 годин).
- KV безкоштовно дозволяє ~1000 записів на добу: Worker пише лише при змінах.
