# Карта відключень світла: вся Україна

Що тут лежить
- `index.html` — сама карта (одна сторінка).
- `data/ua.json` — свіжі графіки по областях. Його переписує робот.
- `scripts/fetch-ua.mjs` — скрипт збору: alerts.org.ua (дані обленерго), для Київської додатково звірка зі svitlo.live.
- `.github/workflows/update.yml` — розклад: 3 рази на добу + кнопка ручного запуску.

Розклад (за Києвом, влітку): 06:00, 14:00, 21:00. Взимку на годину раніше.
Ручне оновлення: GitHub → вкладка Actions → «Update outage data» → Run workflow.

Як це працює
- Збій однієї області не ламає інші: для неї лишаються попередні дані з позначкою «не вдалося оновити».
- Якщо джерело повністю недоступне, файл не перезаписується, а запуск завершується помилкою (GitHub надішле лист).
- Області без графіка в джерелі (або без даних) на карті сірі, це не те саме, що «світло є».

Джерело даних: alerts.org.ua. Посилання на джерело показується на карті. Умова сайту: використання матеріалів лише з посиланням на alerts.org.ua.
